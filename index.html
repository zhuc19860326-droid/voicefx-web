CONNECT YOUR AGENT

接在声音输出与播放之间。

适用于你能访问音频数据的 Agent。先在服务端完成豆包或其他语音 API 的认证，再把解码后的 PCM 传给前端效果器。

Agent / TTS→PCM 音频→VoiceFX→扬声器
import { VoiceFX } from './voicefx.js';

// 由用户点击触发，再启动 AudioContext
const context = new AudioContext();
await context.resume();
const fx = await VoiceFX.create(context, {
  pitch: -5, metal: 0.6, drive: 0.25
});
fx.connect(context.destination);
const stream = await fx.createPCMStream({
  sampleRate: 24000, format: 's16le'
});

// 每个音频包：单声道、有符号 16 位、小端 PCM
stream.enqueue(pcmArrayBuffer);
// 上游本轮语音结束
stream.end();
// 打断 / 取消当前回复
// stream.cancel();
当前版本的接入边界

支持单声道 s16le / Float32 PCM，也可把已有 Web Audio 节点连接至 fx.input。麦克风和实时流保持 1× 速度；文件可独立调整音高与速度。声线控制采用频谱塑形，不是共振峰保持或换人。豆包现成 App 的系统音频、AU / VST3 和虚拟声卡尚未实现。
